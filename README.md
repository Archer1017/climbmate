# ClimbMate 攀岩助手

从全流程攀岩工具迭代为突出“拍岩壁、生成候选路线、保存收藏和记录”的Web App。

本仓库保存经过脱敏的源码快照，属于开发原型。

## 功能

- 首页、路线、行程、装备、训练和攀岩记录。
- 照片上传、手动标点、AI候选路线及草稿收藏。
- 服务端模型代理与浏览器本地持久化。
- 精简记录表单与动态统计。

## 运行

需要 Node.js 22.12+。运行 `npm ci`、`npm run dev`；`npm run build` 生成静态站点，`npm test` 执行单元测试。AI 功能需复制 `.env.example` 为 `.env`，配置自己的接口并执行 `npm run build && npm start`。

## 当前范围

已有React、TypeScript、Vite Web App原型。

- 账户、云同步、真实天气和地图尚未接入。
- AI候选路线需要人工核对，不能作为安全认证。

`npm run build` 成功；`npm test` 的 30 项测试通过。测试使用模拟接口，未调用真实 AI。
